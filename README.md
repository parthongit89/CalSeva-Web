# CalSeva Web - HTML5, CSS3 & JavaScript Specification

Welcome to the **CalSeva Web** official repository. CalSeva is a premier calibration service provider offering high-precision on-site calibration, technical support, and annual maintenance for industrial measurement tools.

This repository contains the complete responsive web application built with pure **HTML5**, **CSS3**, **Vanilla JavaScript**, and **Google Sans Flex**, styled strictly according to the Figma design system (`node-id=638-3`) with zero Node.js build overhead.

---

## Tech Stack & Ecosystem Directory

- [**HTML5 (MDN)**](https://developer.mozilla.org/en-US/docs/Web/HTML) - Semantic & Accessible HTML Markup Standard.
- [**CSS3 & Tailwind CDN**](https://tailwindcss.com/) - Utility-first styling and custom design tokens.
- [**Vanilla JavaScript (MDN)**](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - Lightweight, zero-dependency browser interactivity.
- [**Google Sans Flex Font**](https://fonts.google.com/) - Primary Typography variable font family.
- [**Vercel Edge Network**](https://vercel.com/) - Instant static edge CDN deployment.
- [**Figma Design System**](https://www.figma.com/design/I0MbnU8Xks35mLwtkTcAKI/Projects?node-id=638-3&m=dev) - Primary visual source.

---

## Quickstart & Local Development

No Node.js, npm, or build tools are required!

1. Simply open `index.html` in any web browser.
2. Or serve using any static web server (e.g. Python `python -m http.server`, Live Server extension, etc.).

---

## Deployment to Vercel

1. Push code to `https://github.com/parthongit89/CalSeva-Web.git`.
2. Import repository into [Vercel](https://vercel.com).
3. Select Framework: **Other / Static**.
4. Deploy instantly with zero build step!
